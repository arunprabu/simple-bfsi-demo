# GitHub Spec Kit Workflow

1. **Constitution** — Define the project's core principles, rules, and engineering standards.

2. **Specify** — Describe **what** you want to build and capture the user and business requirements.

3. **Clarify** — Resolve ambiguities, gaps, and unanswered questions in the specification.

4. **Plan** — Decide **how** to build it, including architecture, technologies, and implementation approach.

5. **Tasks** — Break the implementation plan into small, actionable development tasks.

6. **Implement** — Execute the tasks and build the project according to the specification and plan.

**Workflow:** `Constitution → Specify → Clarify → Plan → Tasks → Implement`
